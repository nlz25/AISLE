# World silhouette

Land geometry: Natural Earth, 1:110m land, public domain.
Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson
Terms: https://www.naturalearthdata.com/about/terms-of-use/

`world.svg` is generated by `python3 scripts/build_map.py`. The map shows land only, without political boundaries. Markers represent country groups, positioned near their participating institutions; they are not precise facility locations.
