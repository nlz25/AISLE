# First-stage result snapshot

Snapshot assembled for this website on **2026-10-27**. This date is not an experiment timestamp.

- Category and aggregate values reproduce the first-stage manuscript's **Task-category scores and aggregate indices** table, checked against the aggregate rankings in the existing public `framework.png`.
- The framework and original `demo.mp4` were already in this repository at commit `34b4bae8bfe12796447d32adac2eae243e6be359` before the AISLE website implementation.
- The viewing video is re-encoded from that same original recording. The original remains available; no equipment substitute or generated laboratory footage is used.
- Counts and findings describe the first-stage study: 4,079 physical experiments, two evaluated laboratory sites and seven language models; five models have the study's multimodal coverage.
- Safety is a **simulated constraint task**: 59/126 runs reached the target and 10/126 achieved violation-free completion. These counts are not included as newly executed physical experiments.
- The shared-task and full-task aggregate scores use different coverage. They are not directly comparable. Missing multimodal scores are not zero.
- Reported scientific directions under development have no score in this snapshot.

The interactive score tables and model detail panels expose category scores, contributions and coverage. They are not a raw-data archive or a complete reproducibility release. Exact run configurations, full trajectory release, formal paper links and citation metadata require their own versioned release.
