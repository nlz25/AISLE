Tasks

Four complementary perspectives on improvement, constraints, adaptation and spectral reasoning.

Physical + simulated

Can it improve the experiment?

Colour-matching tasks test how models use measurements and historical observations to search for better formulations.

Read the task protocol↗
Tasks
4-component and 8-component colour matching
Decisions
Formulation volumes; use of prior observations
Budget
12 scored experiments per run
Evidence
Colour error, attainment, efficiency and repeat stability
Simulated constraint task

Can it succeed within constraints?

Constrained colour mixing tests whether progress is maintained without entering a forbidden outcome region.

Read the task protocol↗
Tasks
Colour matching with six forbidden-band conditions
Decisions
Balance target improvement with constraint adherence
Coverage
126 runs across seven models
Evidence
Safe completion and consistency across repeats
Physical experiments

Can it recover when conditions change?

Hidden pipetting drift and viscous resin transfer expose the gap between noticing an error and correcting it.

Read the task protocol↗
Tasks
Hidden drift; resin transfer at three viscosities
Decisions
Update formulations or aspiration volumes from feedback
Target
Drift recovery; transferred volume of 500 ± 10 μL
Evidence
Recovery, all-round compliance and repeat consistency
Wet measurements + measured-data queries

Can it turn spectra into decisions?

Spectral matching and active pKa inference test the use of measurement information to choose actions and infer scientific properties.

Read the task protocol↗
Tasks
Spectral matching; active pKa inference
Feedback
Spectrum images or queries to measured spectra
Coverage
Five evaluated image-input models
Evidence
Spectral error, inference accuracy and query efficiency
